## 🖥️ 페이지 구성

### 1. 네비게이션 (`nav`)
- 고정 헤더 (Fixed Navigation)
- 스크롤 시 배경 블러 효과 및 하단 보더 표시
- 데스크톱: 인라인 링크 / 모바일: 햄버거 메뉴

### 2. 히어로 섹션 (`.hero`)
- 앱 핵심 메시지 및 CTA 버튼
- 폰 목업 UI (CSS로 구현된 앱 화면 미리보기)
- 주요 수치 표시: `100자 이내`, `1일 1줄`, `5가지 이모지`
- 스크롤 인디케이터 애니메이션

### 3. 기능 소개 (`.features`)
6가지 주요 기능을 카드 형태로 소개:

| 기능 | 설명 |
|------|------|
| ✍️ 하루 한 줄 기록 | 하루에 한 번, 100자 이내의 간결한 기록 |
| 🏷️ 5가지 카테고리 | 일상 · 시 · 책 · 노래 가사 · 영화/드라마 |
| 💕 이모지 반응 | ❤️ 💪 😢 🔥 🤔 로 마음 전하기 |
| 📖 나만의 기록장 | 내 기록을 한눈에 모아보기 |
| 🌿 수정 불가의 진심 | 한 번 남긴 글은 수정 불가 |
| 👀 다른 사람의 이야기 | 타인의 한 줄 읽기 및 공감 |

### 4. 사용 방법 (`.how-it-works`)
3단계로 안내:
1. **카테고리를 골라요** — 5가지 중 선택
2. **한 줄을 남겨요** — 100자 이내로 작성
3. **마음을 나눠요** — 이모지 반응으로 공감

### 5. 카테고리 소개 (`.categories`)
5가지 카테고리별 예시 문장과 설명을 카드로 제공:
- 📝 일상 / 🪶 시 / 📖 책 / 🎵 노래 가사 / 🎬 영화·드라마

### 6. 인용문 섹션 (`.quote-section`)
- 앱의 핵심 가치를 전달하는 인용문 블록

### 7. 다운로드 CTA (`.download`)
- 이메일 구독 폼 (출시 알림 사전 등록)
- 개인정보 수집·이용 동의 체크박스 및 상세 안내
- App Store / Google Play 버튼 (준비중 상태)

### 8. 푸터 (`.footer`)
- 브랜드 정보 및 서비스·법적 고지·고객지원 링크

## ⚙️ 주요 기술 구현

### CSS (`style.css`)
- **CSS Custom Properties**: `--warm-50` ~ `--warm-900` 컬러 팔레트로 일관된 디자인 시스템
- **반응형 디자인**: `1024px` / `768px` / `480px` 3단계 미디어쿼리 브레이크포인트
- **CSS Grid & Flexbox**: 기능 카드 3열 그리드, 카테고리 5열 그리드 등
- **시각 효과**: `backdrop-filter` 블러, `box-shadow` 그림자 시스템, 커스텀 애니메이션
- **폰 목업**: 순수 CSS로 구현한 3D 원근감 있는 스마트폰 화면

### JavaScript (`script.js`)
- **네비게이션 스크롤 감지**: 스크롤 위치에 따라 네비게이션 스타일 변경 (`passive` 이벤트)
- **모바일 메뉴 토글**: 햄버거 버튼 클릭 시 모바일 메뉴 열기/닫기
- **스크롤 애니메이션**: `IntersectionObserver`를 활용한 요소 진입 시 페이드업 애니메이션
- **부드러운 스크롤**: 앵커 링크 클릭 시 `smooth scroll` 처리
- **목업 카드 하이라이트**: 3초 간격으로 폰 목업 내 카드 순환 강조
- **이메일 구독 폼 처리**:
  - 이메일 유효성 검사 (정규식)
  - 개인정보 동의 확인
  - `localStorage` 기반 중복 등록 방지
  - 외부 API 호출 (`contact-capture.mirolab.kr`)을 통한 이메일 저장
  - 로딩 상태 및 성공/실패 UI 피드백

## 📱 반응형 브레이크포인트

| 화면 크기 | 주요 변경 사항 |
|-----------|---------------|
| **> 1024px** | 데스크톱 — 2열 히어로, 3열 기능 카드, 5열 카테고리 |
| **768px ~ 1024px** | 태블릿 — 1열 히어로, 2열 기능 카드, 3열 카테고리 |
| **480px ~ 768px** | 모바일 — 햄버거 메뉴, 1열 기능 카드, 2열 카테고리 |
| **< 480px** | 소형 모바일 — 1열 카테고리, 스크롤 인디케이터 숨김 |
